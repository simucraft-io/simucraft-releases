# SimuCraft downloads

SimuCraft is an interactive circuit simulator for learning and tinkering: breadboards, Arduino and ESP32 boards, colour touch screens with LVGL, and bench instruments.

**Download:** the newest Windows installer is under [Releases](https://github.com/simucraft-io/simucraft-releases/releases/latest). Run it, and SimuCraft tells you when a newer version is out.

**Use it in your browser:** [simucraft.io](https://simucraft.io) (coming soon).

**Found a problem?** In SimuCraft choose Help, Report a problem, and email the file it saves to bugs@simucraft.io.

This repository holds only the installers and release notes. The "Source code (zip)" and "Source code (tar.gz)" links GitHub adds to every release contain just this page: download **SimuCraft-Setup-…exe** to install SimuCraft. SimuCraft's own source code is private.
